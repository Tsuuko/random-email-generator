# ランダムメールジェネレーター

ランダムメールジェネレーターは、フォームに素早くランダムなメールアドレスを入力するためのブラウザ拡張機能です。ウェブでのテストやサービス登録時に便利です。

## 機能

- 右クリックメニューからメールアドレスの生成と入力
- カスタマイズ可能なメールアドレス形式
  - ランダム文字列（例：a7b2c9d3@example.com）
  - 単語の組み合わせ（例：apple_banana@example.com）
- ドメイン名のカスタマイズ
- 文字列の長さ設定
- 単語パターンのカスタマイズ

## 使い方

1. 拡張機能をインストールする
2. メールアドレスを入力したいフォームで右クリック
3. メニューから「ランダムメールを生成」を選択
4. 設定したパターンに基づいたメールアドレスが自動的に入力される

## 設定

拡張機能のアイコンをクリックして設定ページを開くか、ブラウザの拡張機能管理ページから設定を開けます。

以下の項目を設定できます：

- **メールアドレスのドメイン**: 生成されるメールアドレスのドメイン部分（例：example.com）
- **メールアドレスの形式**:
  - **ランダム**: ランダムな文字列を生成（例：a7b2c9d3@example.com）
  - **単語の組み合わせ**: ランダムな単語を組み合わせて生成（例：apple_banana@example.com）
- **文字列の長さ**: ランダム形式の場合の文字数
- **単語パターン**: 単語組み合わせ形式の場合のパターン（{word}がランダムな単語に置き換えられる）

## 開発

このプロジェクトは[WXT](https://wxt.dev/)を使って開発されています。

### 必要条件

- Node.js
- pnpm

### 開発環境のセットアップ

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev
```

### ビルド

```bash
# 本番用ビルド
pnpm build
```
